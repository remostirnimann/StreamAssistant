# Stream Assistant add-ons

Home Assistant add-on repository of [Stream Assistant](https://github.com/remostirnimann/StreamAssistant):
Elgato Stream Decks driven directly by Home Assistant.

[![Add this repository to your Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fremostirnimann%2FStreamAssistant-addon)

## Add-ons

- **[Stream Assistant Bridge](stream_assistant_bridge)**: Stream Decks plugged into the
  Home Assistant host. Home Assistant finds it on its own, no pairing code needed.

## Adding the repository by hand

**Settings → Add-ons → Add-on store**, menu ⋮ → **Repositories**, add
`https://github.com/remostirnimann/StreamAssistant-addon`.

This repository is generated from `addon/` in the
[main repository](https://github.com/remostirnimann/StreamAssistant) with every release;
report problems and send changes there.
